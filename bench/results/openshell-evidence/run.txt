## Translator-output findings

- Policies whose translations are IDENTICAL host sets (the translator collapses trusted and conditional hosts, so OpenShell cannot tell them apart): `browse` = `open`
- Harness edits applied to the translator's output before OpenShell would accept and use it:
  - removed `tls: terminate` from 14 endpoints (OpenShell v0.1.8 rejects it: "unknown tls value 'terminate'; omit the field to keep automatic TLS termination")
  - port 443 -> 18080 on 14 endpoints (the translator hard-codes 443; the mock upstream listens on 18080)
  - added `binaries: [/usr/bin/curl]` (the translator emits none, and OpenShell treats an empty binaries list as matching no binary, so the raw policy allows nothing)
  - added `allowed_ips: ["10.99.99.1/32"]` to 14 endpoints (the mock upstream is on a private address)
